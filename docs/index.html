CoCreate-speech-recognition

Toggle any html element to view in speech-recognition mode. Easy configuration and targeting using the speech-recognition and target attribute.

Install

 
npm i @cocreate/speech-recognition

Or you can use cdn link: 

<script>https://cdn.CoCreateJS.com/speech-recognition/latest/CoCreate-speech-recognition.min.js</script>

Usage

This is speech-recognition usage 

                                
                                      <style type="text/css">
                                        #example2{
                                          background-color: white;
                                          }
                                      </style>
                                      <section>
                                        <h2>Only Target</h2>
                                        <button speech-recognition speech-recognition-selector="#example2">With Attr Target</button>
                                        <button speech-recognition >WithOut Target</button>
                                      </section>
                                      <section>
                                        <div id="example2" class="box ">
                                          <h2>#exemple2</h2>
                                            <p>
                                            Lorem ipsum dolor sit amet, consectetur adipiscing elit.
                                            </p>
                                        </div>
                                      </section>
